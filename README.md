# Panagiota Kroustali — Personal Portfolio

This repository hosts my **personal portfolio website**, a clean and responsive landing page that presents my background, skills and work as a **Junior Software Engineer** with a focus on **software and cloud development**.

The goal of the site is to provide a clear entry point to my work, directing visitors to my projects, education and professional profiles.

---

## 🌐 Live Website

👉 https://panagiota-kroustali.github.io

---

## 🎯 Purpose

This portfolio is designed to:

- Present my profile as a Junior Software Engineer
- Highlight my academic background (BSc in Applied Informatics, MSc in Software & Cloud Development)
- Showcase my projects and the technologies behind them
- Act as a professional landing page linked from LinkedIn and my CV

## 💡 Focus Areas

- Software development with Python, Java and JavaScript
- Relational databases (PostgreSQL, MySQL)
- Cloud technologies and containerization (Google Cloud, Docker)
- Web development and responsive design

## ✨ Features

- Responsive layout for desktop, tablet and mobile
- Dark / light theme toggle that remembers the visitor's choice
- Mobile navigation menu
- Smooth scrolling between sections

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (Flexbox, Grid, custom properties)
- **JavaScript** (vanilla, no frameworks)
- **GitHub Pages** (deployment)

The site is intentionally kept lightweight and framework-free to prioritize content and fast loading.

## ▶️ Run Locally

No setup required.

```bash
# clone the repository
git clone https://github.com/panagiota-kroustali/panagiota-kroustali.github.io.git

# then simply open the file in your browser
index.html
```
